# 中秋禮盒 WMS 資料預覽

第一階段桌面程式，用於連接兩個 WMS、保存各自憑證，以及預覽店舖與待處理訂單資料。

## 使用方式

1. 執行 `build\publish\中秋禮盒-WMS預覽.exe`。
2. 選擇網站1或網站2。
3. 輸入該網站的 API ID 與 API Key。
4. 按「安全保存憑證」。API Key 會存入目前 Windows 使用者的 Credential Manager，不會寫在程式或共用槽。
5. 按「取得店舖清單」測試連線並查看表格與安全遮罩 JSON。
6. 按「載入蛋黃酥待處理訂單」。程式會以訂單成立日從 2026/07/01 查到本次執行日，列出商品名稱含「蛋黃酥」或命中指定 SKU 的待處理訂單。
7. 預覽完成後按「匯出 Excel」，選擇儲存位置。活頁簿包含「訂單預覽」與已展開父／子商品的「商品明細」。

每次載入訂單後，畫面會按來源顯示最近同步結果、查詢日期、完成分頁、筆數及最後成功時間。摘要保存在目前 Windows 使用者的本機應用程式資料目錄，只含同步狀態，不含訂單 JSON、API ID、API Key 或 Token。失敗會留下安全錯誤摘要，但不會清除先前的最後成功時間。

訂單預覽會送出 `date_min=2026-07-01`、`date_max=本次執行日` 與 `status=F`，逐頁取得待處理訂單。訂單成立日只用來限制初次載入範圍；程式不再以 `arrival_date` 篩選，空白或格式異常仍會列出並保留原值。API 文件沒有 `arrival_date` 查詢參數，因此程式不會送出未定義的到貨日條件。

兩來源採相同商品條件：父商品或 `items` 子商品名稱含「蛋黃酥」，或 SKU 為 `4710964232411`、`4710964232565`、`4710964232435`。程式可解析陣列或 JSON 文字形式的 `products`；Flavor 組合品優先使用 `items`，缺少 `items` 時以禮盒 SKU 查詢 BOM，並在 Excel 商品明細中保留禮盒與主商品的對應。

睿驛的 `source` 是賣場名稱，`source_key` 才是通路代碼。程式將 `source_key=shopee` 顯示為「蝦皮賣場」，並另存原 `source` 為賣場名稱。商品畫面上的完整文案由父商品 `name` 與 `spec` 組成；若 `spec` 或 `name` 含明確日期區間，程式會保留區間並將區間內唯一的星期一列為「指定出貨日（推導）」，不覆寫 API `arrival_date`。

## 安全規則

- API Key、Bearer Token、Authorization、姓名、電話、Email、地址及收件資訊不會顯示在預覽 JSON。
- 已保存的 API Key 不會回顯在畫面。
- 網站1與網站2的憑證分開保存。
- 每個 Windows 使用者需要在自己的電腦上保存一次憑證。
